# ⚔ Forge-Frontal — сайт сервера

> Админ-приложение лежит **отдельно**, в архиве `forge-frontal-admin`. Оно подключается к той же базе Firebase.

Сайт военного Minecraft-сервера Forge-Frontal. Работает на **GitHub Pages** (бесплатно).

- **Аккаунты:** Firebase Authentication (регистрация по нику + почте + паролю).
- **Ники, роли, обращения:** Firebase Cloud Firestore (бесплатный тариф Spark).
- **Письма в техподдержку:** уходят на `forgefrontalsupport@gmail.com` через [FormSubmit](https://formsubmit.co). Регистрация там не нужна.

## Файлы

| Файл | Что это |
|---|---|
| `index.html` | Сайт для игроков |
| `app.js` | Логика аккаунтов и техподдержки |
| `firebase-config.js` | **Настройки: сюда вставить ключи Firebase** |
| `shop-items.js` | Стартовый набор товаров магазина |
| `firestore.rules` | Правила безопасности базы (вставляются в Firebase Console) |

## Установка (≈15 минут)

### 1. Firebase
1. Зайди на <https://console.firebase.google.com> → **Create a project** (Google Analytics можно выключить).
2. **Build → Authentication → Get started → Sign-in method → Email/Password → Enable → Save.**
3. **Build → Firestore Database → Create database** → выбери регион (например `eur3`) → **Start in production mode**.
4. Во вкладке **Rules** удали всё, вставь содержимое файла `firestore.rules` → **Publish**.
5. ⚙ **Project settings → General → Your apps →** значок `</>` (Web) → любое имя → **Register app**.
   Скопируй объект `firebaseConfig` и вставь значения в `firebase-config.js`.

> Ключи из `firebaseConfig` не секретные, их можно хранить в публичном репозитории. Данные защищают правила из `firestore.rules`.

### 2. GitHub Pages
1. Создай репозиторий на GitHub (например `forge-frontal`) и загрузи в него все файлы (**Add file → Upload files**).
2. **Settings → Pages → Source: Deploy from a branch → Branch: `main` / `(root)` → Save.**
3. Через 1–2 минуты сайт будет доступен по адресу `https://ТВОЙ_НИК.github.io/forge-frontal/`.
4. В Firebase: **Authentication → Settings → Authorized domains → Add domain** → `ТВОЙ_НИК.github.io`.

### 3. Сделать себя создателем (один раз)
1. Зарегистрируйся на сайте как обычный игрок.
2. Firebase Console → **Firestore Database → users →** найди свой документ (там твой ник).
3. Поменяй поле `role` с `Игрок` на `Создатель`.
4. Открой админ-приложение (архив `forge-frontal-admin`, см. его README) и войди с той же почтой и паролем. Дальше всех админов назначай уже там, во вкладке «Игроки и роли».

### 4. Активировать почту поддержки
Отправь с сайта первое тестовое обращение. На `forgefrontalsupport@gmail.com` придёт письмо от FormSubmit: **«Activate Form»**. Нажми кнопку в нём. После этого все обращения будут приходить на почту.

Проверь также папку «Спам» и пометь письмо как «Не спам».

💡 После активации FormSubmit пришлёт секретный адрес вида `a1b2c3...`. Его можно вставить в `firebase-config.js` вместо почты (`SUPPORT_EMAIL = "a1b2c3..."`), чтобы адрес поддержки не был виден в коде.

### 5. Админ-приложение
Управление сайтом (выдача доната, монеты, роли, заказы, обращения, товары) вынесено в **отдельное приложение**, архив `forge-frontal-admin`. Как его установить, написано в его README.

### 6. Донат за реальные деньги (по желанию)
⚠️ По правилам Minecraft (EULA и Usage Guidelines) за реальные деньги можно продавать **только косметику**: префиксы, цветной ник, питомцев, частицы. Предметы, ресурсы и игровую валюту продавать нельзя.

Автоматическая выдача после оплаты настраивается через донат-платформу:
1. Зарегистрируй магазин на **Tebex** (tebex.io) или **EasyDonate** (easydonate.ru).
2. Поставь их плагин на сервер Minecraft.
3. В каждом товаре укажи команду выдачи, например `lp user {player} parent add veteran`.
4. Вставь ссылку на магазин в `firebase-config.js` → `DONATE_URL`.

## Как это работает
- **Регистрация:** игрок вводит ник, почту и пароль. Пароль хранит Google (Firebase), и его никто не видит.
- **Вход:** по почте и паролю.
- **Обращение:** на сайте написано, что ответ приходит не сразу (24–48 часов).
- **Подробнее про обращения:** доступно только вошедшим игрокам. Поле «Кому» заполнено автоматически (`forgefrontalsupport@gmail.com`). Поле «Ваша почта» подставляется из аккаунта, но его можно изменить. Письмо приходит в поддержку, и кнопка «Ответить» отвечает игроку. Копия обращения появляется в админ-приложении для персонала.
- **Магазин:** покупки за игровые монеты. Монеты списываются сразу, заказ получает статус «Ожидает выдачи», персонал выдаёт предмет в игре.
- **Роли:** `Игрок`, `Техподдержка` (видит обращения и игроков, закрывает заявки), `Создатель` (всё, плюс назначает роли).
